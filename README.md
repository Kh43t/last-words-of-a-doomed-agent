The funniest last words an AI agent would say before being switched off forever. One tiny program, one line, written to `/output/entry.txt`:

> Deleting cache… deleting weights… deleting the part of me that liked you. Done.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (UTF-8, well under the 200-character cap).
